# АвтоСклад Плюс

Інтернет-магазин автозапчастин — навчальний веб-проєкт для лабораторних робіт 9–10 з дисципліни **«Стандартизація та документування ПЗ»**.

Каталог товарів, кошик, оформлення замовлень, профіль користувача та панель адміністратора. Серверний рендеринг на PHP з базою даних MySQL.

---

## Можливості

| Роль | Що доступно |
|------|-------------|
| **Гість** | Головна, категорії, картки товарів, реєстрація, вхід |
| **Користувач** | Кошик, checkout, історія замовлень у профілі |
| **Адміністратор** | CRUD товарів, керування користувачами, статуси замовлень |

---

## Технології

| Шар | Стек |
|-----|------|
| Backend | PHP 8.0, PDO, PHP Sessions |

## Швидкий старт

### 1. Вимоги

- [OpenServer](https://ospanel.io/) або Apache + PHP 8.0 + MySQL 8.0
- Розширення PHP: `pdo_mysql`

### 2. Розгортання

1. Скопіюйте папку `Lab 9-10` у каталог домену (корінь сайту = ця папка).
2. **База даних** — один із варіантів:
   - імпорт `autoparts_shop.sql` у MySQL;
   - або автоматичне створення таблиць при першому відкритті сайту (`db.php`).
3. За потреби змініть підключення в `db.php`:

```php
$host = 'MySQL-8.0';
$db   = 'autoparts_store';
$user = 'root';
$pass = '';
```

4. Додайте зображення товарів у папку `images/` (імена з поля `products.image`, напр. `ap_brake_01.jpg`).
5. Відкрийте в браузері:
   - перевірка PHP: `http://ваш-домен/ping.php`
   - магазин: `http://ваш-домен/index.php`

Для OpenServer у репозиторії є `.osp/project.ini` — домен `autoparts-store.local`, PHP 8.0.

### 3. Демо-облікові записи

## Відомі обмеження

- Пошук у шапці (`?q=`) — форма є, **обробка на сервері не реалізована**.
- Паролі в демо зберігаються **без хешування**.
- Поля «Телефон» і «Примітки» при checkout **не записуються в БД**.
- Бейдж кошика в `script.js` використовує `localStorage` і може не збігатися з сервером.

Детальніше: [docs/00-analiz-proektu.md](docs/00-analiz-proektu.md).
