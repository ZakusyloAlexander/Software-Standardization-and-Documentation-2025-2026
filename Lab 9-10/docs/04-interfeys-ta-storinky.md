# Інтерфейс користувача та опис сторінок

## 4.1 Загальний макет

Усі сторінки (крім `ping.php`, `delete_users.php`) використують спільний каркас:

1. **Шапка** (`header.php`) — логотип, навігація, пошук, кошик, вхід/профіль/адмін.
2. **`<main class="main container">`** — контент сторінки.
3. **Підвал** (`footer.php`) — 4 колонки, контакти, копірайт.

**Кольорова схема та типографіка** визначені в `app.css` (темна шапка, акцентні кнопки, картки товарів).

## 4.2 Глобальна навігація

| Пункт меню | Ціль | Примітка |
|------------|------|----------|
| Головна | `index.php` | — |
| Каталог | `index.php#products` | Якір до сітки товарів |
| Категорії | `index.php#categories-title` | — |
| Доставка | `#delivery` | Секція на головній |
| Контакти | `#contacts` | Футер |
| Пошук | `GET index.php?q=` | **Не працює** |
| Кошик | `cart.php` | Потрібен вхід |
| Увійти / Профіль / Вихід / Адмін | відповідні PHP | Залежить від сесії |

## 4.3 Сторінка `index.php`

### Секції

| Секція | CSS-клас | Зміст |
|--------|----------|-------|
| Hero | `.hero-section` | «АвтоСклад Плюс», статистика 30+ позицій, 6 категорій |
| Переваги | `.features-section` | Доставка, гарантія, оплата, підбір |
| Категорії | `.categories-section` | 6 посилань `category.php?id=` з іконками ⚙️🛑🛞⚡❄️🚗 |
| Товари | `.products-section` | До 8 товарів, `ORDER BY created_at DESC` |
| CTA | `.cta-section` | Заклик перейти до категорій |

### Елементи картки товару

- Зображення `images/{image}`
- Бейдж залишку (`stock < 5`, `stock == 0`)
- Кнопка `.btn-add-to-cart` → POST на `cart.php` через JS
- Мікророзмітка schema.org `Product`, `Offer`

## 4.4 Сторінка `category.php`

| Параметр | `id` — ціле, ID категорії |
|----------|---------------------------|
| Breadcrumbs | Головна → назва категорії |
| Заголовок | «Категорія: {name}», лічильник товарів |
| Навігація | Горизонтальний список усіх категорій, активна — клас `.active` |
| Сітка | Аналогічна головній, усі товари категорії |

## 4.5 Сторінка `product.php`

| Блок | Опис |
|------|------|
| Галерея | Одне головне зображення |
| Ціна, наявність | `stock > 0` → «На складі (N шт.)» |
| Опис | `description` з БД, `nl2br(htmlspecialchars())` |
| Особливості | Статичний список (гарантія, доставка) |
| Форма | `quantity` 1..stock, `POST cart.php` `add_to_cart` |
| Схожі | До 4 товарів тієї ж `category_id` |

**Примітка:** блок рейтингу ⭐⭐⭐⭐⭐ — декоративний, не з БД.

## 4.6 Сторінка `cart.php`

| Дія | Механізм |
|-----|----------|
| Додати | POST `add_to_cart`, `product_id`, `quantity` |
| Змінити кількість | POST `update_quantity`, `cart_id`, `quantity`; кнопки ± через inline JS |
| Видалити | GET `?remove={cart_id}` |
| Оформити | Посилання `checkout.php` |

Порожній кошик: блок `.empty-cart` з посиланням на каталог.

## 4.7 Сторінка `checkout.php`

- Ліва колонка: список позицій з кошика, сума.
- Права форма: `shipping_address` (обов’язково), `phone`, `notes` (не зберігаються).
- POST → створення замовлення, очищення кошика, повідомлення з номером `order_id`.

## 4.8 Авторизація

| Сторінка | Поля | Поведінка |
|----------|------|-----------|
| `login.php` | email, password | Порівняння пароля в plaintext |
| `register.php` | name, email, password | Перевірка унікальності email |
| `profile.php` | — | Ім’я, email, таблиця замовлень |

Посилання на реєстрацію з login **відсутнє** у розмітці login.php (є в футері).

## 4.9 Сторінка `admin.php`

Три секції в `.admin-container`:

1. **Товари** — форма додавання/редагування, таблиця з мініатюрами.
2. **Користувачі** — ролі, promote/demote, delete.
3. **Замовлення** — зміна статусу через `<select onchange="submit">`.

Доступ лише при `$_SESSION['role'] === 'admin'`.

## 4.10 Клієнтські сценарії в `script.js`

| Подія | Поведінка |
|-------|-----------|
| Клік `.btn-add-to-cart` | `preventDefault`, динамічна форма POST → `cart.php` |
| Неавторизований користувач | Редірект на `login.php` з боку сервера після POST |
| `localStorage.cartCount` | Лише візуальний бейдж, не оновлюється після серверного додавання |

## 4.11 Доступність (a11y)

- `role="banner"`, `navigation`, `main`, `contentinfo"`
- `aria-label` на кнопках кошика та категоріях
- `.visually-hidden` для label пошуку
- `prefers-reduced-motion` вимикає scroll-reveal анімації
