### Конфліктні ліцензії

На момент генерації **критичних конфліктів** між MIT-проєктом і production-залежностями не виявлено. Повний машинний звіт: `licenses.txt`. Для детального списку виконайте:

```bash
npm run licenses
license-checker --production --csv --out licenses-full.csv
```
